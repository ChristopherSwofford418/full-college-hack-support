Support

Help for building study sets, importing your own course materials, and managing College Hack Plus.

Start a course

Open Study, add a course code or choose a common college course, choose a topic, then select flashcards, practice questions, or a tutorial.

Bring in a reading

Open Sources, choose Import readings, and select a PDF, DOCX, or plain-text file you are permitted to use. Your imported reading stays associated with the course workspace it supports.

Review your learning

Use Evidence Map to review source-linked prompts. Use Repair Room after a missed recall attempt to compare the answer with the source material.

Subscription help

College Hack Plus purchases are processed by Apple. To manage or cancel a subscription, open iPhone Settings, select your Apple Account, then select Subscriptions. For purchase issues, use Apple’s Report a Problem service.

Feedback

When reporting an issue, include the course code, the screen you were using, and a screenshot when possible. Do not include private course content unless it is necessary to explain the issue.
